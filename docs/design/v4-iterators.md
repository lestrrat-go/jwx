# Iterator Support (iter.Seq)

## Motivation

v3 provided index-based access (`Key(idx int)`) and `Keys() []string` for iteration, requiring manual loops and allocating intermediate slices. Go 1.23+ range-over-func enables idiomatic `for ... range` iteration without allocations.

## Changes

### JWK Set

**`All() iter.Seq2[int, Key]`** — iterates over all keys in the set.

```go
for i, key := range set.All() {
    fmt.Printf("key %d: %s\n", i, key.KeyType())
}
```

**`Fields() iter.Seq2[string, any]`** — iterates over non-key fields (private parameters).

```go
for name, value := range set.Fields() {
    fmt.Printf("%s = %v\n", name, value)
}
```

Both methods are implemented on `set` and `cachedSet`. They hold a read lock for the duration of iteration.

### JWT Token

**`Claims() iter.Seq2[string, any]`** — iterates over all claims (standard + private).

```go
for name, value := range token.Claims() {
    fmt.Printf("%s = %v\n", name, value)
}
```

Standard claims are yielded first (in field order), then private claims. Generated by `genjwt` for both `jwt.Token` and `openid.Token`.

## Existing APIs retained

- `Key(idx int) (Key, bool)` — random access by index
- `Keys() []string` — returns field name slice
- `Len() int` — key count

These remain for cases where index-based access or a materialized slice is needed.

## Migration guide (v3 → v4)

```go
// v3: iterate JWK set
for i := 0; i < set.Len(); i++ {
    key, _ := set.Key(i)
    // use key
}

// v4: range-over-func
for _, key := range set.All() {
    // use key
}
```

```go
// v3: iterate JWT claims
for _, name := range token.Keys() {
    var v any
    token.Get(name, &v)
    // use name, v
}

// v4: range-over-func
for name, v := range token.Claims() {
    // use name, v
}
```
